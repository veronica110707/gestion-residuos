# Gestión de Residuos Urbanos

Este proyecto consiste en la simulación de un sistema de gestión de residuos urbanos desarrollado en Java. El objetivo ha sido aplicar un flujo de trabajo completo basado en el análisis, diseño y desarrollo de software, utilizando UML como base del diseño y Git para el control de versiones.

El sistema representa la gestión de elementos como vehículos, rutas, contenedores y operarios dentro de un entorno urbano. A partir de un diseño previo realizado en UML, se ha implementado la estructura de clases en Java manteniendo la coherencia entre el modelo y el código.

Durante el desarrollo se ha trabajado la organización del proyecto y la relación entre diseño e implementación, priorizando que el código refleje correctamente el modelo definido en los diagramas.

En el proyecto se han utilizado herramientas como Java para el desarrollo, Git y GitHub para el control de versiones y draw.io para la creación de los diagramas UML. El trabajo se ha organizado mediante ramas para separar las distintas fases del desarrollo, como el diseño UML y la implementación de las clases.

El sistema se ha basado en un diagrama de casos de uso y un diagrama de clases, a partir de los cuales se ha definido la estructura del código fuente.

Este proyecto ha sido realizado como práctica de desarrollo de software.
